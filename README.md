# General Knowledge Resources

A clean, minimal, distraction-free index of **22 foundational open-access masterworks** spanning cognitive science, market economics, literary essays, and historical archives.

Designed in `C:\YashHQ\General-Knowledge-Library` adopting the layout, typography, and minimalist structure of [`C:\YashHQ\mlresources-main`](file:///C:/YashHQ/mlresources-main/mlresources-main/index.html).

---

## ✦ Design Architecture (mlresources-main pattern)

- **Palette**: Dark gradient canvas (`--bg-primary: #0a0a0a` to `--bg-secondary: #1a1a1a`) with electric cyan links (`--link-color: #4fc3f7`) and subtle borders (`--border-color: #333`). Includes a light theme toggle.
- **Header & Navigation Bar**: Clean `.nav-bar` with live resource counter, instant filter search, saved bookmarks toggle, and theme switch.
- **Table of Contents**: Structured `.toc` multi-column jump list linking to each category section.
- **Minimal Text Cards**: Each resource features:
  - 16:9 visual preview thumbnail with subtle border.
  - Source & course code pill (`<code>YALE • PSYC 110</code>`).
  - Clickable title link (`↗`) with cyan glow on hover.
  - Concise 1-sentence description.
  - Bookmark star for personal study list curation.
